# FAQ (English) — AI Film Pipeline Skill

> This skill is a **prompt/storyboard workflow tool**. It does NOT generate videos directly. Rights of generated images follow the terms of the tool you use.

## What It Does

**Q1. What does this skill do?**
Turns a script/story paragraph into a complete storyboard + prompt package: scene breakdown, shot type, camera movement, plus prompt sets and character-consistency notes.

**Q2. Does it generate videos directly?**
No. It is a prompt/storyboard workflow tool. You copy the prompts into image/video tools (e.g. Jimo image-to-video) to generate footage.

**Q3. I can't write prompts. Can I still use it?**
Yes — that is exactly its purpose. Write your idea in plain language; it writes the professional prompts for you.

**Q4. Language support?**
Chinese and English scripts both supported. Jimo version outputs Chinese; Image2.5 / Midjourney versions output prompt formats (Chinese by default, English on request).

**Q5. Who is it for?**
AI short-film creators, comic-drama producers, storyboard artists, creators making cinematic AI images, and teams needing batch storyboards.

## Usage

**Q13. Trigger keywords?**
storyboard / short film script / shot / image prompt / AI film / widescreen / concept art / storyboard script. English descriptions of the same tasks also work.

**Q14. How long a script can it handle?**
Best results: one scene or 200–500 characters per input. Split long scripts into segments.

**Q15. Which prompt set should I use?**
GPT Image2.5: formal storyboards, precise composition, in-image text. Midjourney: concept posters, key visuals, atmosphere. Jimo: Chinese descriptions, Asian characters, shots for image-to-video. Mix and match.

**Q16. How is character consistency handled?**
Each set ends with a character-consistency note. Copy it into your tool's reference/character-lock features (e.g. MJ --cref, Jimo reference image). The skill provides notes; the tool performs the lock.

**Q17. Can I edit a single shot?**
Yes. Specify the shot number or description; only that shot is rewritten.

**Q18. How do I use the generated prompts?**
Copy into GPT Image / Midjourney / Jimo, generate the image, then use Jimo or similar for image-to-video.

**Q19. Free vs full version?**
Free: basic script breakdown, one generic prompt set. Full: three prompt sets, camera-movement labels, character-consistency notes, single-shot editing, batch scene processing, priority support.
